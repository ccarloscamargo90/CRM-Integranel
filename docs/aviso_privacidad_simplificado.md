3. Asignar a un vendedor de Intergranel para gestión comercial.
4. Verificar el cumplimiento fiscal cruzando con la Lista 69-B SAT.

**No utilizamos sus datos para fines de marketing masivo ni los compartimos
con terceros con fines comerciales.**
